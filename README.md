HOW TO RUN:

1. Clone or download the GitHub repository.

2. Open the project folder in a terminal.

Start the Backend
Navigate to the backend folder:

cd backend,
npm install,
node index.js

The backend will run on:

http://localhost:5001

Start the Frontend
Open a second terminal window and navigate to the frontend folder:

cd change++_project,
npm install,
npm run dev

Vite will provide a local URL (typically http://localhost:5173). Open that URL in a web browser to use the application.

The backend and frontend must both be running at the same time for the application to work properly.
